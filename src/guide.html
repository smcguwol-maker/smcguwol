실제 배포 주소와 정식 공개 여부는 최신 작업 인수인계에서 확인하세요.

1. 홈페이지 확인하기

전달받은 미리보기 링크로 확인해 주세요. 이 사이트는 다섯 페이지를 연결하는 구조이므로 압축 안의 HTML 파일을 더블클릭하는 방식으로 검수하지 않습니다.

PC에서 소스를 확인하려면 Node.js 20 이상에서 아래 명령을 실행한 후 터미널에 표시된 로컬 주소를 엽니다.

npm run build
npm run preview

2. 요금·사진·문구 바꾸기

연락처, 사진 목록, 요금과 FAQ는 content/site.json에서 관리합니다. 페이지별 본문은 src/pages/, 첫 화면은 src/index.html입니다.

상세 수정 방법 · 이용 도우미 무료 운영 안내

3. 파일 보관과 배포

원본 src, scripts, content, assets, docs를 함께 보관하세요. 완성 파일은 빌드 시 public에 생성됩니다.

현재 고객 Cloudflare Pages는 직접 업로드 방식입니다. GitHub 파일 저장만으로 배포되지 않습니다. public의 내용 전체를 ZIP으로 올리며, 기존 배포를 먼저 삭제할 필요는 없습니다.

미리보기는 npm run build:preview로 만들고 Preview 환경에 올립니다. 정식 반영 전에는 배포 안내와 최신 승인 범위를 확인해 주세요.

4. 기능 범위

네이버 예약·전화·카카오톡·지도·SNS·유튜브로 연결합니다. 상담 도우미는 공개된 매장 이용 안내를 제공합니다. 자동 알림톡, 예약자 검증, 출입 비밀번호 전달은 제외되어 있습니다.

AI는 무료 플랜의 일일 한도 안에서 사용하며, 한도나 장애 시 기본 안내 버튼과 연락 경로를 이용할 수 있습니다. 유료 플랜 전환 전에는 비용 조건을 다시 확인해야 합니다.
