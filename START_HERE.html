시안 확인부터 사진·요금 수정, 전체 파일 보관까지. 처음 필요한 내용을 이 페이지에 모았습니다.

홈페이지 시안 열기 →

이 파일은 정식 공개 전 검토본의 안내입니다. 고객 Pages 미리보기와 Chrome 화면 크기 검수를 진행했습니다. 실기기·Safari 확인과 도메인 연결은 남아 있습니다. 최신 확인 주소는 작업 인수인계를 참고하세요.

시안 보기자주 하는 수정파일 보관공개 순서문제 해결

1. 시안 확인하기

  1. 전달받은 ZIP 파일을 먼저 압축 해제합니다.
  2. smcguwol 폴더 안의 이 파일을 열고 위의 ‘홈페이지 시안 열기’를 누릅니다.
  3. 직접 열 때는 public → index.html을 선택합니다. src/index.html은 제작용 원본입니다.

PC 브라우저에서 확인할 수 있습니다. 문구·사진은 인터넷 없이도 보이며, 예약·지도·카카오톡 등 외부 링크는 인터넷이나 해당 앱이 필요합니다. 휴대폰 실사용 확인은 배포 후 미리보기 링크에서 진행합니다.

수정 의견은 ‘첫 화면 문구’, ‘3번방 사진’, ‘요금표’처럼 위치와 바꿀 내용을 함께 적어주시면 정확히 반영하기 좋습니다.

2. 자주 하는 수정

배포 연결을 마친 뒤에는 고객 GitHub 저장소에서 파일을 수정하고 저장하면 홈페이지에 자동 반영됩니다. 현재는 연결 전이며, 자동 반영은 배포 설정을 마친 후에 사용할 수 있습니다.

요금·연락처·주소·예약 링크
content/site.json
갤러리 사진·제목·설명
assets/ + content/site.json
첫 화면·소개·주차 안내 문구
src/index.html
자주 묻는 질문
content/site.json의 faq

요금 수정 예시

content/site.json에서 해당 방을 찾고 price만 바꿉니다. 금액은 30분 기준입니다.

{ "name": "Room 3·4 · 업라이트", "price": "3,500원" }

기본 1시간 금액은 2배로 자동 계산됩니다. 예를 들어 30분 3,500원이면 1시간 7,000원입니다. 개인룸의 변동은 임의 계산하지 않습니다.

사진 교체 순서

  1. assets/에 새 사진을 올립니다. 예: room-3-new.jpg.
  2. content/site.json의 해당 사진 src를 assets/room-3-new.jpg로 바꿉니다.
  3. width·height에 실제 사진 크기를 적고, alt·caption·description을 맞춥니다.
  4. 저장(Commit changes) 후 빌드·배포 완료를 확인합니다. 현재 직접 업로드 방식에서는 파일 저장만으로 미리보기가 갱신되지 않습니다.

사진을 먼저 올린 뒤 설정을 바꾸면 아직 없는 사진을 참조해 배포가 실패하는 일을 줄일 수 있습니다. PC와 휴대폰에서 바뀐 사진·문구를 확인하세요.

모든 수정 방법과 예외는 상세 수정 안내에 있습니다. public/의 파일은 자동 생성되므로 직접 수정하지 않습니다.

3. 소유·보관·이전

계정 구성은 고객 GitHub 저장소와 고객 Cloudflare Pages입니다. 저장소는 smcguwol-maker/smcguwol입니다. GitHub 연결과 파일 저장 권한을 확인했습니다. 이번 제작본은 codex/smc-design-review 검토 브랜치용이며, Pages 직접 업로드 미리보기를 사용합니다. Git 자동 배포 연결은 남아 있습니다.

원본을 보관하거나 다른 개발자에게 전달할 때는 smcguwol 폴더 전체를 함께 전달하세요. 사진·문구·디자인 원본과 배포 파일, 수정 안내가 포함되어 있습니다.

src/
HTML·CSS·JavaScript 제작 원본
content/, assets/
업체 정보와 전체 확보 사진·로고
scripts/
배포 파일 생성·검사 코드
public/
실제 홈페이지에 올릴 완성 파일
docs/, reference-materials/
수정·배포 안내와 자료 근거

다른 개발자는 Node.js 20 이상에서 npm run build로 홈페이지를 다시 만들고 public/을 정적 호스팅으로 이전할 수 있습니다. 원본 사진과 외부 저작물은 각각의 권리를 따릅니다.

4. 온라인 공개 순서

  1. 고객 GitHub의 파일 저장 권한을 확인하고 제작 파일을 업로드합니다.
  2. 고객 Cloudflare Pages에 저장소를 연결하고 미리보기 주소를 만듭니다.
  3. 휴대폰·태블릿·PC 화면과 예약·전화·지도 버튼을 검수합니다.
  4. 확정 도메인 근처연습실co.kr을 연결하고 HTTPS를 확인합니다.
  5. 정식 공개용 검색 설정으로 전환하고 네이버 소유 확인·사이트맵 제출을 진행합니다.

네이버 예약·알림은 기존 네이버 서비스를 사용합니다. 카카오톡 자동 예약 알림은 이번 구성에 포함하지 않았습니다.

설정값은 배포·도메인·검색 등록 안내, 계정 준비는 계정 준비 안내에 있습니다. 실제 화면 검수와 연결 결과는 검수 기록에서 확인할 수 있습니다.

5. 문제가 생겼을 때

사진이나 디자인이 안 보여요.

ZIP을 완전히 압축 해제했는지, public/index.html을 열었는지 확인하세요. HTML 파일만 따로 옮기면 사진과 스타일 경로가 끊어집니다. public 폴더를 통째로 유지하세요.

수정했는데 홈페이지가 그대로예요.

GitHub에 변경을 저장했는지, Cloudflare의 자동 배포가 완료됐는지 확인하세요. 배포 완료 후 새로고침합니다. 연결 전에는 파일을 수정해도 온라인 홈페이지에 자동 반영되지 않습니다.

수정 후 배포가 실패했어요.

배포 로그의 오류 메시지를 확인하세요. JSON의 큰따옴표·쉼표, 사진 경로·파일명, 사진 크기를 먼저 확인하면 좋습니다. 임의로 전체 파일을 삭제하지 말고 수정 전 내용으로 해당 변경을 되돌린 뒤 다시 배포하세요.

네이버 예약 버튼을 누르면 업체 소개가 나와요.

고객이 제공한 링크는 네이버 플레이스 홈으로 연결됩니다. 그 화면의 ‘예약’ 탭에서 공간·일시를 선택하면 됩니다. 야마하 C6 홀은 전화로 예약 가능 시간을 문의하도록 안내합니다.

이 안내 파일과 원본 자료는 홈페이지 방문자용 배포 폴더 밖에 보관됩니다. 현재 공개 상태와 미완료 항목은 검수 기록을 기준으로 확인하세요.
