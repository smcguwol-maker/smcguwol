# SMC 방문 통계 확인

## 고객 확인 방법

1. [SMC 방문 통계](https://dash.cloudflare.com/733b1c8faa19799bf480b1192f473635/web-analytics/sites)를 엽니다.
2. 고객님의 기존 Cloudflare 계정으로 로그인합니다. 홈페이지 소식 관리에서 받는 이메일 인증과는 별도의 Cloudflare 로그인입니다.
3. SMC 고객 계정에서 `근처연습실co.kr`을 선택합니다. 한글 주소 대신 `xn--co-002iq89dzga40o12n.kr`로 표시될 수도 있습니다.
4. Visits(방문 횟수) 또는 Page views(페이지 조회수)를 누릅니다. 기간 선택 메뉴(예: Last 24 hours)에서 원하는 기간으로 바꾸면 해당 기간의 통계가 표시됩니다.

홈페이지 [소식 관리](https://xn--co-002iq89dzga40o12n.kr/admin/)에 로그인한 뒤 상단의 **방문 통계 열기**를 눌러도 같은 통계 화면으로 이동할 수 있습니다. 이 바로가기는 2026-09-28 23:23 KST에 정식 배포했습니다.

통계를 보기 위해 홈페이지 파일을 다시 업로드하거나 새 사이트를 만들 필요는 없습니다. 소식·영상·사진은 기존 홈페이지의 소식 관리에서 수정합니다.

## 수치의 의미

- 방문 횟수: 외부 사이트나 직접 주소로 들어온 방문입니다. 같은 사람이 다시 방문하면 여러 번 포함될 수 있으므로 ‘서로 다른 방문자 몇 명’과 같지 않습니다.
- 페이지 조회수: 이용자가 페이지를 연 횟수입니다. 한 번 방문해서 여러 페이지를 열면 조회수가 더 많아질 수 있습니다.
- 일부 광고 차단 기능, 자바스크립트 제한 및 집계 지연으로 실제 이용과 차이가 날 수 있습니다. 제작자와 고객의 접속도 포함될 수 있습니다.
- 현재 Cloudflare Web Analytics 기본 기능을 사용합니다. 별도 유료 통계 서비스를 신청하지 않았습니다.
