## 목표와 판단 기준

**인천 구월동에서 실제로 운영하는 음악연습실 SMC라는 인상과, 나에게 맞는 방을 찾아 예약하기 쉬운 구성을 함께 만든다.**

- 첫 화면에서 ‘인천 구월동 음악연습실 SMC’를 HTML 글자로 읽을 수 있다.
- SMC 로고·실제 실내 사진·방 번호·악기·위치가 디자인의 재료가 된다.
- 개인 악기 연습과 피아노 연습을 모두 보여준다. C6 홀만 보고 모든 방이 같은 규모라고 오해하지 않게 한다.
- 모바일에서 공간·요금·예약을 빠르게 찾는다. 개성 때문에 가독성이나 예약 편의를 포기하지 않는다.
- 기존 원페이지 계약과 HTML/CSS/JavaScript·Cloudflare Pages 구성을 유지한다. 별도 CMS, 자체 예약·결제, 유료 디자인 서비스는 추가하지 않는다.

현재 기능 시안의 차콜·라임색, 장식용 영문, 원형 24H 표시는 기능상 오류는 아니지만, SMC의 파란 로고·우드 톤 사진과 연결되는 이유가 약하다. 이 평가는 현재 소스와 확보된 이미지에 근거하며, 실제 렌더링 검수 결과는 아니다.

### 확인 범위와 제외 후보

- AIR: 최초 이동은 시간 초과했지만 이어서 본문과 실제 화면을 확인했다.
- 스테이폴리오: 메인과 호텔 카라멜 상세 화면을 확인했다. 참고 대상은 상세 페이지이며, 메인의 프로모션·자동 슬라이드는 채택하지 않는다.
- RYSE: 상단 메뉴·워드마크와 소개 구간을 확인했다. 스크롤 호출에 시간 초과가 있어 정밀 동작 검수는 하지 않았다. 이번 레퍼런스에서는 브랜드 표현 원칙만 보조적으로 채택한다.
- PIRATE: 검색으로 연습실 예약 서비스임을 확인했으나, 관찰한 브라우저 화면에서 핵심 메인 영역이 충분히 표시되지 않아 시각 레퍼런스에서는 제외했다. 전체 사이트가 고장 났다고 판단하지 않는다.
- The Modern House: 검색 결과는 확인했지만 브라우저에서 보안 확인 화면이 계속 표시되어 시각 평가에서 제외했다. 우회나 CAPTCHA 해결은 하지 않았다.

## SMC 공통 디자인 규칙

1. 로고 원본을 재그리거나 다른 심볼로 바꾸지 않는다. 로고의 흰 배경을 주변 여백에 자연스럽게 연결한다. 파란색은 브랜드와 링크·초점 등에 제한적으로 쓰고 네이버 초록은 예약 행동에 사용한다.
2. 장식용 대형 영어 문구와 원형 24H 도장은 빼는 방향으로 검토한다. 대신 ‘24시간 연중무휴’, ‘30분 기준 요금 · 최소 1시간 예약’을 읽기 쉬운 실제 안내로 쓴다.
3. 제목·본문·설명 크기의 차이를 분명히 한다. 모바일 본문은 16px 전후, 보조 설명은 14px 전후부터 검토한다. 한글 단어 줄바꿈·행간·버튼 높이를 실제 화면에서 확인한다. 모든 영문을 일괄 삭제할 필요는 없다.
4. 모든 섹션을 둥근 카드 3개로 반복하지 않는다. 공간은 사진+캡션, 요금은 표, 이용 안내는 짧은 단계, FAQ는 접기/펼치기로 정보 형태에 맞춘다.
5. 실제 사진만 사용한다. 실내를 더 넓거나 고급스럽게 보이게 생성·합성하지 않는다. 원본 비율을 살리고 악기와 출입 공간이 잘리지 않는지 확인한다. 큰 사진과 다른 방 사진의 크기 차이에 목적을 둔다.
6. 모바일 하단 예약 진입점과 전화 연결은 유지한다. 큰 인트로·자동 영상·과한 스크롤 효과·불필요한 슬라이더를 넣지 않는다.
7. 확정 요금의 단위는 30분으로 유지하며 최소 1시간 조건을 함께 보여준다. C6 홀·개인룸 문의 안내와 네이버 플레이스의 예약 탭 안내도 유지한다.
8. 제목·주소·공간 설명·요금을 이미지 안에만 넣지 않는다. 기존 정적 HTML과 SEO 설정을 유지하고, 차별화를 위해 지역 키워드를 과도하게 반복하지 않는다.

## 다음 단계와 완료 기준

- 구현 완료: A/B의 첫 화면과 공간 소개를 부분 시안으로 만들었다. 다음에는 실제 모바일 화면을 비교하고 선택한 안을 전체 원페이지에 적용한다.
- 같은 SMC 자료, 같은 390px 모바일 폭, 같은 예약 목적을 사용해 비교한다. PC 구성은 보조적으로 확인한다.
- 첫 화면에서 지역·업종·SMC·예약 진입점을 쉽게 찾는지 확인한다.
- 작은 개인실, 업라이트, C6 홀이 서로 다른 공간이라는 점과 방 번호가 정확한지 확인한다.
- 사진이 작거나 과도하게 잘려 공간 상태를 알 수 없는지, 한글 줄바꿈과 로고가 어색한지 확인한다.
- 선택한 안을 구현한 다음 320/390/768/1440px, 키보드, 200% 확대, 고정 예약 버튼 겹침을 실제 브라우저로 확인한다. 현재 프로젝트의 실제 렌더링 검수는 여전히 대기 상태다.
- 렌더링을 확인할 수 없는 시각화는 ‘디자인 제안 이미지’로 표시한다. 실제 홈페이지 화면이나 테스트 통과 증거로 제시하지 않는다.

레퍼런스는 디자인 원리를 참고하기 위한 링크다. 외부 사이트의 사진·로고·문구·코드를 SMC 배포 파일로 복사하지 않는다. 외부 유료 폰트·템플릿·서비스 구매나 기존 계약 변경은 이번 선정 작업에 포함하지 않는다.
