# SMC 디자인 검토 02

## 목적

첫 방문자가 실제 공간을 보고 개인 악기 연습·피아노 연습·C6 홀을 구분한 다음, 요금과 예약 경로를 이해하도록 한다. A/B는 같은 실제 사진, 확정 요금과 업체 정보를 사용한다. 아직 최종안은 선택하지 않았다.

## 디자인 기준

| 항목 | A · 공간의 온도 | B · 오늘의 연습 |
| --- | --- | --- |
| 인상 | 차분한 스튜디오 소개 | 선명한 음악 연습공간 안내 |
| 바탕 / 본문 | `#F4F1E9` / `#252B25` | `#FFFFFF` / `#142852` |
| 강조 | `#47573D` | `#124BD8` |
| 제목 | 시스템 명조, PC 최대 56px / 모바일 35px | 시스템 고딕, PC 최대 80px / 모바일 49px |
| 본문 | PC 14–15px / 모바일 13px 중심 | 동일 |
| 공간 구성 | PC 사진 3열, 모바일 세로 배치 | PC 사진·설명 좌우 배치, 모바일 세로 배치 |
| 첫 화면 | Room 1 실사진, 짧은 지역 소개 | Room 1 실사진, 개인 악기·피아노·홀로 이동 |

공통 원칙:

- 최대 본문 폭 1240px. PC 좌우 여백 56px 이상, 모바일 20px. 700px·1000px 분기.
- 새 외부 글꼴 다운로드 없이 운영체제 글꼴을 사용한다. 운영체제별 한글 모양 차이는 실기기 검수 대상으로 남긴다.
- 실제 공간 사진의 구조·장비를 바꾸지 않는다. 방 번호·설명·가격은 사진 가까이에 둔다.
- 본문 가격은 `content/site.json`에서 생성한다. Room 1·3·5 소개와 전체 요금표가 같은 원본을 사용한다.
- 30분 기준·최소 1시간을 함께 표시한다. 변동 요금을 임의 계산하지 않는다.
- 일반 공간은 네이버 예약, C6 홀과 개인룸은 전화 문의로 구분한다.
- 모바일 하단에 예약·전화 버튼을 유지한다. 자동 재생, 불필요한 도입 애니메이션, 가상 후기·가상 공간은 추가하지 않는다.
- 키보드 포커스, 본문 건너뛰기, 사진 대체 설명과 움직임 줄이기 설정을 유지한다.

## 디자인 검토 도구 평가

[Impeccable](https://github.com/pbakaus/impeccable)의 공개 설명에서 제시하는 정보 위계·명확성·반응형 검토 관점을 첫 화면에 수동 적용했다. 외부 스킬이나 실행 파일은 설치하지 않았으며, 해당 도구를 실행한 결과나 점수로 주장하지 않는다.

적용 결과: A의 제목을 두 줄로 줄여 모바일 사진 노출을 앞당겼고, B의 숨겨지는 줄바꿈 앞 공백을 보완했다. 첫 화면만 보고 전체 완성도를 판단하지 않도록 공간·가격 섹션까지 비교 범위를 확장했다.
