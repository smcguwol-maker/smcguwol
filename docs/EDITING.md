# SMC 홈페이지 수정 방법

이 홈페이지는 고객님 GitHub 저장소에 있는 HTML/CSS/JavaScript 정적 사이트입니다. 별도 관리자 화면은 없으며, 파일을 수정하는 방식입니다. 제작자 계정이나 전용 플랫폼에 묶이지 않습니다.

ZIP으로 전달받았다면 먼저 압축을 풀고 `START_HERE.html`을 열어 간단한 안내를 볼 수 있습니다. 이 문서는 상세 수정 방법입니다.

## 처음 한 번 알아두기

| 바꾸려는 내용 | 수정할 파일 |
| --- | --- |
| 업체명·연락처·링크·사진 목록·요금표 | `content/site.json` |
| 자주 묻는 질문과 답변 | `content/site.json`의 `faq` |
| 주소(화면·주소 복사·검색용 정보) | `content/site.json`의 `address` |
| 네이버 사이트 소유 확인 코드 | `content/site.json`의 `naverVerification` |
| 첫 화면 문장, 소개 문구, 주차·이용 안내 | `src/index.html` |
| 색상·글자·배치 | `src/styles.css` |
| 메뉴·사진 확대·주소 복사 동작 | `src/app.js` |
| 사진 파일 | `assets/` 폴더 |
| 상단·하단 로고 및 파비콘 | `assets/smc-guwol-logo.jpg`, `content/site.json`의 `logo` |
| 배포용 완성 파일 | `public/` 폴더 — 직접 수정하지 마세요. 빌드 시 다시 만들어집니다. |

GitHub에서 해당 파일을 열고 연필 모양(Edit)을 누른 뒤, 변경 내용을 저장(Commit changes)합니다. Cloudflare Pages의 GitHub 연결을 마친 뒤에는 GitHub의 변경으로 홈페이지가 자동 빌드·배포됩니다. 연결 전에는 저장소 파일만 바뀝니다.

## 문구 수정

`src/index.html`에서 현재 보이는 문장을 검색해 글자만 바꾸세요. `<h1>`, `<p>`, `<a>` 같은 태그와 `{{BOOKING}}` 같은 항목은 유지합니다. 업체의 지역·업종이 담긴 H1은 하나만 유지합니다.

## 연락처·예약 주소 수정

`content/site.json`에서 `phone`, `address`, `links.booking` 등을 바꾸세요. 문자열을 둘러싼 큰따옴표와 쉼표는 유지해야 합니다. 예약 링크는 고객님 네이버 플레이스/예약 주소로 통일되어 있습니다.

주소는 아래 네 항목으로 나뉘어 있습니다. `streetAddress`는 도로명·번지·층, `addressLocality`는 구, `addressRegion`은 시, `addressCountry`는 국가 코드입니다.

```json
"address": {
  "streetAddress": "인하로489번길 16, 10층",
  "addressLocality": "남동구",
  "addressRegion": "인천광역시",
  "addressCountry": "KR"
}
```

이 항목을 수정하면 화면의 주소, 주소 복사, 검색용 구조화 데이터가 함께 바뀝니다. 빌드 코드를 따로 수정할 필요가 없습니다. 다른 지역으로 이전하면 소개 문구·FAQ·지도 링크도 실제 위치에 맞게 함께 확인해 주세요.

## 자주 묻는 질문 수정

`content/site.json`의 `faq`에서 `question`은 질문, `answer`는 답변입니다. 글자만 수정하고 큰따옴표와 쉼표는 유지하세요. 질문을 추가할 때는 기존 질문 항목을 복사합니다. 이 내용은 빌드된 HTML 본문에 포함되며 별도 스크립트 없이 열고 닫을 수 있습니다.

현재는 최소 예약시간, 트럼펫·관악기와 드럼 이용 제한, 24시간 운영, C6 홀 전화 문의, 주차 안내를 담았습니다. 운영시간·예약 정책·주차 안내가 바뀌면 해당 FAQ와 본문도 함께 수정합니다.

## 사진 교체

통합 첫 페이지의 첫 화면·C6 홀은 `hero`, 개인 연습실은 `gallery[1]`, 업라이트는 `gallery[2]`를 사용합니다(배열 번호는 0부터). 이 순서를 유지하고 해당 항목을 교체하세요. 방 번호·제목은 `src/index.html`에 있으므로 방 자체를 바꾸면 함께 수정해야 합니다. `gallery[0]`은 공유 대표 이미지입니다.

1. `assets/`에 원본 사진을 업로드합니다. 파일명은 영문·숫자·하이픈을 권장합니다. 예: `practice-room-01.jpg`.
2. `content/site.json`의 `hero.src` 또는 `gallery` 항목의 `src`에 `assets/practice-room-01.jpg`처럼 경로를 적습니다.
3. `alt`는 실제 보이는 공간의 설명, `caption`은 화면에 보일 짧은 제목입니다. 갤러리의 `description`은 어떤 악기를 연습할 수 있는지 등 선택에 도움을 주는 설명입니다. 검색어를 반복해 넣지 않습니다. 첫 화면 사진을 교체하면 `hero.caption`의 방 번호·공간 이름도 함께 바꾸세요.
4. `width`, `height`에 원본 픽셀 크기를 적습니다. 가로 사진은 가급적 1,600px 이상 원본을 권장하되 파일은 적절히 압축하세요.
5. 저장한 뒤 사진이 잘리지 않았는지 PC·휴대폰에서 확인합니다. 첫 화면 사진 위치는 `hero.position`의 `50% 50%` 값을 조정할 수 있습니다.

사진은 `assets/`에 먼저 올리고 나서 `content/site.json`을 바꾸세요. 빌드 시 설정에서 사용하는 사진만 `public/assets/`에 복사하며, 교체된 예전 배포 사진은 출력에서 정리합니다. `assets/`의 원본은 자동 삭제하지 않습니다. 예전 사진을 다시 사용하려면 설정에서 해당 파일을 선택할 수 있습니다.

현재 첫 화면은 음악 공간이 바로 드러나도록 5번 야마하 C6 홀 사진을 사용하며 사진 위에 해당 공간명을 표시합니다. 갤러리는 네이버 예약에서 확보한 Room 1·3·5의 가로 1000px 사진입니다. 기존 본사 복도·Room 6·14 사진은 확보본으로 보관합니다. 로고는 고객이 첨부한 1254×1254 JPEG를 변경 없이 사용했습니다.

로고를 바꾸려면 `assets/smc-guwol-logo.jpg`를 교체하고 `logo.width`, `logo.height`, `logo.alt`를 맞춥니다. 파일명이나 형식을 바꾸는 경우 `logo.src`를 수정하세요. JPG·PNG·WebP·AVIF의 파비콘 파일 형식은 빌드 시 자동 반영됩니다. 로고는 실제 공간을 보여주는 사진 갤러리에 포함하지 않습니다.

정식 공개 후 링크 공유에 사용할 대표 사진은 `gallery`의 첫 번째 사진입니다. 공유 사진을 바꾸려면 사진 순서를 바꾸세요. 첫 화면 사진은 `hero`에서 별도로 선택합니다. 사진 교체 후 외부 서비스의 미리보기에 반영되는 시점은 해당 서비스의 캐시에 따라 달라질 수 있습니다.

## 이용요금 수정

고객님이 전달한 네이버 플레이스 캡처의 6개 항목을 `rates`에 반영했습니다. 현재 표는 **30분당 요금**이며 **최소 1시간 예약** 조건입니다. `price`에는 30분 기준 금액을 입력합니다. 금액 아래의 **1시간 요금은 자동으로 2배 계산**하므로 따로 수정하지 않습니다. 예를 들어 현재 시간제 연습실 항목은 다음과 같습니다.

```json
"rates": [
  { "name": "시간제 연습실", "price": "3,500원" }
]
```

첫 2,500원 항목은 네이버 예약에서 확인한 Room 1 블루투스 작은방입니다. 요금표의 방 번호·이름도 같은 예약 목록을 기준으로 정리했습니다. 요금이나 방 구성이 바뀌면 해당 행의 `name`과 `price`를 함께 수정합니다. 개인룸은 캡처대로 `변동`으로 표시합니다.

고정 금액은 `3,500원` 또는 `3500원`처럼 입력하세요. 이 경우 1시간 금액 `7,000원`이 자동 표시됩니다. `변동`, `별도 문의`처럼 고정 금액이 아닌 항목은 1시간 금액을 계산하지 않습니다. 할인·추가요금은 자동 적용하지 않으며 최종 예약 화면의 금액을 확인하도록 안내합니다.

요금 단위를 바꾸는 경우 `scripts/build.mjs`의 표 제목·열 이름과 시간당 요금 계산, `src/index.html`의 이용 안내, `content/site.json`의 `rateNote`·`description`도 함께 바꾸세요. 30분 요금을 1시간 금액으로 잘못 표기하지 않도록 주의합니다. 운영시간 24시간을 상담 가능 시간 24시간으로 바꾸지 않습니다.

## 공개 전 안전장치

지금 `publish`는 `false`입니다. 시안 안내와 검색 제외 설정이 적용되고, 공식 주소를 임의로 만들어 검색엔진에 전달하지 않습니다. 이 상태는 비공개 인증 기능이 아닙니다. 공개 저장소의 파일이나 공유한 시안 주소는 아는 사람이 열어볼 수 있습니다.

사진·요금표·도메인은 고객 확인을 반영하여 `approvals`가 모두 `true`입니다. `url`은 정확한 고객 도메인 `https://근처연습실co.kr/`로 입력했습니다. 도메인 철자가 확정됐다는 의미이며 DNS 연결이나 배포가 완료됐다는 뜻은 아닙니다.

고객 Cloudflare 계정에 배포하고 실제 화면·버튼·도메인 연결을 확인한 후, 정식 공개 승인에 따라 `publish`를 `true`로 변경하면 canonical·sitemap·robots가 생성됩니다. 현재는 미리보기 배포 상태이며 도메인 연결과 공개 승인이 남아 `publish: false`를 유지합니다. 한글 도메인은 검색용 URL에서 Punycode로 자동 변환되며, `근처연습실.co.kr`로 점을 추가하면 다른 주소가 됩니다.

`publish`는 따옴표 없는 `true` 또는 `false`로 입력합니다. `"false"`처럼 문자열로 적으면 빌드가 오류를 알려줍니다. 사진의 `width`·`height`도 큰따옴표 없는 양의 정수로 적으세요.

## 네이버 사이트 소유 확인

정식 도메인이 연결된 뒤 네이버 서치어드바이저에서 안내하는 **HTML 태그** 방법을 선택합니다. 발급된 `<meta name="naver-site-verification" content="...">`에서 `content`의 값만 복사해 `content/site.json`의 `naverVerification`에 넣으세요. 태그 전체를 붙여넣지 않습니다.

코드를 저장하고 자동 배포가 끝나면 HTML의 `<head>`에 확인 태그가 포함됩니다. 그 뒤 네이버에서 소유 확인을 완료합니다. 현재 이 값은 비어 있으며 소유 확인·사이트맵 제출은 아직 하지 않았습니다. 자세한 순서는 `DEPLOYMENT.md`를 참고하세요.

## 다른 개발자에게 전달 / 이전

GitHub의 Code → Download ZIP으로 모든 파일을 내려받을 수 있습니다. `src`, `content`, `assets`, `scripts`, `public`, `docs`를 함께 전달하세요. Node.js 20 이상에서 `npm run build` 후 `public/`만 정적 호스팅에 올리면 됩니다. 별도 런타임 서버·DB·유료 라이브러리가 필요하지 않습니다. 이미지 및 외부 저작물은 각각의 권리를 따릅니다.

오류가 생기면 급히 파일을 삭제하지 말고 이전 커밋을 확인해 해당 변경만 되돌립니다. 배포가 실패하면 Cloudflare의 빌드 로그를 확인하세요.
